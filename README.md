# Portfolio Single Page UI

A responsive TypeScript + HTML + CSS implementation of the supplied portfolio design.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Customize

- Update personal copy, links, projects and tech stack in `src/main.ts`.
- Replace the cropped reference assets in `src/assets/` with your own portrait and project screenshots.
- Connect the `Download CV` action to a PDF in `public/`.
- Change global colors and spacing using the CSS variables at the top of `src/styles.css`.
